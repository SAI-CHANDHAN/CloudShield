# CIS-S3-003: S3 versioning is not enabled

Severity: MEDIUM. Category: DATA_PROTECTION.

## What it means
Versioning is off, so an overwrite or delete permanently replaces the previous object.

## Attack scenario
An attacker or ransomware with write access overwrites or deletes objects and the original data cannot be recovered. Accidental deletes by administrators have the same effect.

## Evidence to check
- `aws s3api get-bucket-versioning --bucket <name>`
- Whether MFA Delete or Object Lock is configured
- CloudTrail data events for `DeleteObject` and `PutObject` from unexpected principals
- Whether the bucket holds data that must be recoverable

## Related controls
S3 versioning, MFA Delete, S3 Object Lock, lifecycle rules for old versions, cross-region replication.

## Remediation
Enable versioning. Add lifecycle rules that expire noncurrent versions to control cost. Consider Object Lock or MFA Delete for critical data.
