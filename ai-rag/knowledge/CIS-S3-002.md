# CIS-S3-002: S3 server-side encryption is absent

Severity: HIGH. Category: DATA_PROTECTION.

## What it means
The bucket has no default server-side encryption configuration, so objects written without an encryption header are not guaranteed to be encrypted at rest.

## Attack scenario
Someone with access to the underlying storage, a copied snapshot or misdirected access to raw objects can read data in plaintext. Without a KMS key there is also no separate key policy to limit who can decrypt.

## Evidence to check
- `aws s3api get-bucket-encryption --bucket <name>` (returns ServerSideEncryptionConfigurationNotFoundError when absent)
- Whether existing objects are encrypted: S3 Inventory encryption status
- Sensitivity of the data stored in the bucket

## Related controls
CIS AWS Foundations 2.1.1, SSE-S3 or SSE-KMS default encryption, bucket policy denying unencrypted uploads, KMS key policies.

## Remediation
Enable default encryption (SSE-KMS for sensitive data, SSE-S3 otherwise). Add a bucket policy that denies `s3:PutObject` without encryption. Re-copy existing objects in place to encrypt them.
